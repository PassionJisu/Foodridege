# Foodridge

광주·전남 대학가의 **남는 음식을 순환**시키고, 조리학과 학생의 **외식 키친(친구카세)** 과 외국인 유학생용 **MealPick 맵**을 한 앱에서 다루는 Flutter 프로젝트입니다.

지금은 **서버/DB 없이 데모 계정**으로 역할별 화면을 확인할 수 있습니다. Firebase Authentication · Firestore는 패키지만 들어 있고, 실제 로그인·저장은 `DemoAuthStore`와 메모리 Provider가 담당합니다.

---

## 한 줄 요약

| 축 | 무엇을 하는가 |
|----|----------------|
| **환승반찬** | 당일 반찬을 자판기에 넣고, 학생이 1,000원에 가져간다. |
| **친구카세** | 조리학과 팀이 학교 식당에서 키친을 열고, 식권·응원·리뷰로 참여한다. |
| **MealPick** | 배민 등에 잘 안 나오는 외국인 운영 가게를 맵/목록으로 보여 준다. |
| **수거·입고** | 기관이 입고를 신청하면 기사가 수거·자판기 번호를 부여한다. |

앱은 **역할(대학생 / 점주 / 기관 / 운송기사 / 관리자)** 에 따라 같은 하단 탭을 쓰되, 못 쓰는 메뉴는 막아 둡니다.

---

## 누가 무엇을 쓰나

로그인 후 화면은 역할마다 홈 인사·마이페이지 메뉴가 달라집니다. 하단 탭은 공통입니다.

| 탭 | 이름 | 대학생 | 점주 | 기관 | 기사 | 관리자 |
|----|------|:------:|:----:|:----:|:----:|:------:|
| 1 | 홈 | ○ | ○ | ○ | ○ | ○ |
| 2 | 친구카세 | ○ | ✕ | ✕ | ✕ | ○ |
| 3 | 환승반찬 | ○ | ✕ | ○ | ○ | ○ |
| 4 | MealPick | ○ | ○ | ✕ | ✕ | ○ |

- **대학생**: 환승반찬 조회, 친구카세(식권·응원·리뷰), MealPick, 기여 무게 표시
- **점주**: MealPick 가게 쪽 흐름, 마이페이지에서 가게 관련 메뉴
- **기관**: 자판기 입고 신청(지점 선택 없음) → 매매 신청 내역
- **운송기사**: 수거 동선(네이버맵), 환승반찬 입고(번호 1~120), 수거 대상 목록
- **관리자**: 위 기능 + 신고 관리, 입고 확정 등 운영 메뉴

대학생 가입 시 **일반 한국인** / **외국인(교환학생)** 을 고릅니다.  
교환학생은 **학교 정보 + 체류 시작일·종료일**로 가입하고, **체류 종료일 다음날부터 로그인하면 자동 탈퇴**됩니다.

## 핵심 기능과 비즈니스 로직

### 1. 환승반찬 (자판기)

남는 반찬을 캠퍼스 자판기에 넣고, 학생은 앱에서 **재고만 조회**합니다. 앱 안 예약·결제는 없습니다.

- 가격 **1,000원**, 기여 무게는 **이용 1회 = 200g**
- 기사 입고: 지점 선택 없이 **전역 번호 1~120**을 순서대로 부여
- 당일 반찬만 올리고, 사진·반찬명·수량을 입력합니다
- 기관은 점심 마감 전에 입고를 신청하고, 기사가 **수거 대상 목록**에서 수거 완료 → 관리자가 입고 확정하는 흐름입니다 (데모는 로컬 목록)

### 2. 친구카세

광주·전남 조리학과 6개 팀이 **학교 식당에서 키친**을 엽니다. 운영 안은 **9월 리뷰용 지난 일정 + 10월 1~4일 예약 일정**입니다.

**식권**

- 학교당 **100장**, 같은 날 **1장만** 예약
- 결제 **1,000원** (키오스크 추가 결제 없음)
- **무료 식권**(리뷰 5회마다 1장, 홈/포스터/마이페이지에서 보유 수량 확인)이 있으면  
  1) 보유 식권을 눌러 사용 여부 확인 → 일정 화면으로 이동  
  2) 결제 화면에서 **무료 식권 사용** vs **1,000원 결제**를 다시 고름
- 발권 직후 리뷰 화면으로 가지 않고, *식권이 완료되었습니다. 식사를 마친 후 리뷰를 남겨주세요* 안내만 띄웁니다
- 리뷰는 **식권 예약 내역** 또는 **리뷰 탭**에서만 작성합니다

**응원**

- 유저당 **하루 1회**, 한 팀만 응원
- 랭킹 화면은 순위가 바뀌면 행이 움직이고, 데모에서는 다른 이용자 응원을 흉내 내 실시간처럼 보이게 합니다

**리뷰 리워드**

- 리뷰 1회마다 카운트, **5회마다 무료 식권 1장**

### 3. MealPick (외국인 가게 맵)

공공 급식·대형 배달 앱과 겹치지 않게, **외국인 운영 소규모 가게**(할랄/비건/채식 등)를 소개합니다. 화면 카피는 영어입니다.

- 목록 필터 + 지도에서 가게 선택 → 상세·예약(데모)
- 지도: **Android/iOS**에서는 네이버맵 SDK, **Windows 등**에서는 SDK가 없어 정적 지도/핀으로 대체합니다

### 4. 수거·동선

기사 홈에서 **수거 동선**을 보면 광주 정차 지점과 길안내(네이버맵 앱 또는 웹)가 열립니다.  
수거 대상 목록은 기관이 올린 `pending` 신청을 보여주고, 수거 완료 시 `collected`로 바뀝니다.

## 아키텍처

역할은 달라도 **하나의 셸(`YouthShell`)** 을 씁니다. 권한은 `UserRole`의 `canAccess*` 로 막습니다.

```
로그인(AuthGate)
    └── YouthShell (하단 탭 공통)
            ├── 홈 / 마이페이지
            ├── 친구카세
            ├── 환승반찬
            └── MealPick
```

```
lib/
├── main.dart                 # Provider 등록, 네이버맵 초기화 시도
├── app.dart                  # MaterialApp, AuthGate
├── models/                   # 사용자, 역할, 식권, 자판기, 가게, 수거 신청
├── data/seed_data.dart       # 팀·일정·자판기·가게 더미
├── providers/                # 화면이 구독하는 상태 (메모리)
│   ├── auth_provider.dart
│   ├── chingu_provider.dart
│   ├── vending_provider.dart
│   ├── foodridge_provider.dart
│   └── sale_provider.dart    # 입고/수거 신청 (로컬)
├── services/
│   ├── demo_auth_store.dart  # 데모 계정·회원가입·자동 탈퇴
│   └── naver_map_service.dart
├── screens/auth/             # 로그인, 역할 선택, 회원가입
├── screens/youth/            # 이용자 탭
└── screens/provider/         # 점주·기관·기사·관리자 전용 화면
```

**상태 관리:** `provider` (`ChangeNotifier`).  
**데이터:** 시드 + 앱이 켜져 있는 동안만 유지. 재실행하면 데모 계정 기본값으로 돌아갑니다 (회원가입으로 추가한 계정은 프로세스 메모리에만 있습니다).

**인증 흐름**

1. `AuthGate` → 미로그인 시 `LoginScreen`
2. 데모 칩 또는 이메일/`demo1234`로 `DemoAuthStore.signIn`
3. 교환학생이고 체류 기간이 지났으면 계정 삭제 후 로그인 거부
4. 성공 시 `YouthShell`

**지도**

- `flutter_naver_map`은 Android·iOS만 지원합니다
- `HostNaverMap`: SDK가 준비되면 네이티브 맵, 아니면 네이버 정적 지도(실패 시 핀만)

## 데모 계정

비밀번호는 모두 **`demo1234`** 입니다. 로그인 화면의 역할 칩을 누르면 이메일이 채워집니다.

| 역할 | 이메일 |
|------|--------|
| 대학생 | `student@foodridge.kr` |
| 점주 | `owner@foodridge.kr` |
| 기관 | `org@foodridge.kr` |
| 운송기사 | `driver@foodridge.kr` |
| 관리자 | `admin@foodridge.kr` |

- 대학생 데모는 **한국인**, 무료 식권 **2장**을 들고 시작합니다
- 관리자 회원가입 시크릿: `FOODRIDGE_ADMIN_2026`
- 예시 대학: 전남대학교 · 광주교육대학교 · 국립목포대학교 · 국립목포해양대학교 · 국립순천대학교  
  (친구카세 팀은 전남대·광주여대·순천대·광주대·호남대·조선대)

## 실행

```bash
flutter pub get
flutter run
```

- **친구카세·환승반찬 UI**는 Windows에서도 동작합니다
- **네이버 동적 지도**(확대·마커 탭)는 **Android 기기/에뮬레이터 또는 iOS**에서 실행해야 합니다  
  Windows에서는 정적 지도로 대체됩니다
- 네이버맵 Client ID 등은 `lib/core/config/naver_config.dart` 에 있습니다  
  Android 패키지 / iOS Bundle ID: `com.foodridge.foodridge`

음식 구경·나누기 커뮤니티, 스탬프·칭호, 키오스크 현장 추가 결제, 자판기 앱 내 결제, Firebase 실연동은 현재 범위에 없습니다.

## 화면을 빠르게 보려면

1. `student@foodridge.kr` 로 로그인 → 홈에서 무료 식권 → 친구카세 일정·결제·리뷰 탭
